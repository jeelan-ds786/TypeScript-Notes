

# Optional Parameters (`?`)

Optional parameters allow a function argument to be omitted.

### Syntax

```ts
function greet(name?: string) {
  console.log(name);
}
```

Valid:

```ts
greet("Fareed");
greet();
```

### What TypeScript Actually Does

```ts
function greet(name?: string)
```

is roughly equivalent to:

```ts
function greet(
  name: string | undefined
)
```

### Quick Revision

- `?` means argument may be omitted.
    
- Internally becomes `Type | undefined`.
    

# Why Use Optional Parameters?

Without optional parameter:

```ts
function greet(name: string) {
  console.log(name);
}
```

Must provide:

```ts
greet("Fareed");
```

❌

```ts
greet();
```

Error

---

With optional parameter:

```ts
function greet(name?: string) {
  console.log(name);
}
```

Both work.

### Real Example

```ts
function createUser(
  name: string,
  role?: string
) {}
```

Usage:

```ts
createUser("Fareed");
createUser("Fareed", "Admin");
```

### Interview Takeaway

> Optional parameters make APIs more flexible.

### Quick Revision

- Use when argument isn't always needed.
    

# Optional Parameter vs Default Value

### Optional

```ts
function greet(name?: string) {
  console.log(name);
}
```

Call:

```ts
greet();
```

Output:

```txt
undefined
```

---

### Default Value

```ts
function greet(name = "Guest") {
  console.log(name);
}
```

Call:

```ts
greet();
```

Output:

```txt
Guest
```

### Preferred

If you have a sensible fallback:

```ts
function greet(name = "Guest")
```

### Quick Revision

- Optional → undefined possible.
    
- Default value → safer.
    

# Why Assign `null`?

### Example

```ts
let selectedUser: string | null =
  null;
```

Meaning:

```txt
Currently no user selected
```

Later:

```ts
selectedUser = "Fareed";
```

### Real World

```ts
let currentUser: User | null = null;
```

Before login:

```txt
No logged-in user
```

After login:

```txt
User object
```

### Interview Takeaway

> Null often represents an intentional absence of a value.

### Quick Revision

- `null` = deliberately empty.
    

# Null vs Undefined

This is a very common interview question.

### Undefined

```ts
let name;
console.log(name);
```

Output:

```txt
undefined
```

Meaning:

```txt
Value was never assigned
```

---

### Null

```ts
let name = null;
```

Meaning:

```txt
I intentionally set it to empty
```

### Quick Revision

- undefined → missing value.
    
- null → intentional empty value.
    

# Comparison

### Undefined

```ts
let user;
```

JavaScript assigns:

```ts
user = undefined;
```

Automatically.

---

### Null

```ts
let user = null;
```

Developer assigns it manually.

### Table

|Feature|undefined|null|
|---|---|---|
|Assigned Automatically|✅|❌|
|Assigned By Developer|❌|✅|
|Means|Missing value|Intentional empty value|
|Typeof Result|`"undefined"`|`"object"` (JS bug)|

### Interview Trap

```ts
typeof null
```

returns:

```txt
object
```

Historical JavaScript bug.

### Quick Revision

- `typeof null === "object"` ← Famous interview question.
    

# Nullish Coalescing (`??`)

Introduced to handle `null` and `undefined` safely.

### Syntax

```ts
value ?? fallback
```

Meaning:

```txt
If value is null or undefined
use fallback
otherwise use value
```

### Example

```ts
let userName = null;

console.log(
  userName ?? "Guest"
);
```

Output:

```txt
Guest
```

### Quick Revision

- `??` only checks null and undefined.
    

# Why Not Use `||`?

### Using OR

```ts
let count = 0;

console.log(count || 10);
```

Output:

```txt
10
```

Problem:

```txt
0 is treated as false
```

---

### Using Nullish Coalescing

```ts
let count = 0;

console.log(count ?? 10);
```

Output:

```txt
0
```

Correct.

### Quick Revision

- `||` checks falsy values.
    
- `??` checks only nullish values.
    

# Falsy Values in JavaScript

```ts
false
0
""
null
undefined
NaN
```

### OR Operator

```ts
value || fallback
```

Triggers for ALL falsy values.

---

### Nullish Operator

```ts
value ?? fallback
```

Triggers only for:

```ts
null
undefined
```

### Example

```ts
"" || "Guest"
```

Output:

```txt
Guest
```

---

```ts
"" ?? "Guest"
```

Output:

```txt
""
```

### Interview Takeaway

> Use `??` when `0`, `false`, and empty strings are valid values.

### Quick Revision

- `??` is usually safer than `||` for defaults.
    

# Optional Parameter + Nullish Coalescing

Very common pattern.

### Example

```ts
function greet(name?: string) {
  console.log(name ?? "Guest");
}
```

Calls:

```ts
greet();
```

Output:

```txt
Guest
```

```ts
greet("Fareed");
```

Output:

```txt
Fareed
```

### Quick Revision

- Optional params and `??` work very well together.
