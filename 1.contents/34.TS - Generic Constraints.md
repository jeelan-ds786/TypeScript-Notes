# Generic Constraints (TypeScript)

Generic constraints control **what types are allowed** for a generic parameter.

Instead of accepting **any type**, you can restrict it using `extends`.

**Quick Revision:**

> `extends` in generics means **"must satisfy this shape or type."**

# 1. Single Generic (`<T>`)

Works with **any type**.

```ts
function identity<T>(value: T): T {
    return value;
}
```

Usage:

```ts
identity("Hello");
identity(100);
identity(true);
```

**Use when:** One type is enough.

# 2. Multiple Generics (`<T, U>`)

Use multiple placeholders when values have different types.

```ts
function pair<T, U>(first: T, second: U) {
    return { first, second };
}
```

Usage:

```ts
pair("Fareed", 24);
```

Result:

```ts
{
  first: string;
  second: number;
}
```

**Common interview use:**

- Key → Value
    
- Request → Response
    
- Input → Output
    

# 3. Three or More Generics (`<T, K, V>`)

```ts
function createEntry<K, V>(key: K, value: V) {
    return { key, value };
}
```

Common names:

- `T` → Type
    
- `K` → Key
    
- `V` → Value
    
- `U` → Second Type
    
- `R` → Return Type
    

Example:

```ts
Map<K, V>
```

# 4. `T extends object`

Only objects are allowed.

```ts
function merge<T extends object>(obj: T) {
    return obj;
}
```

✅ Works

```ts
merge({ name: "Fareed" });
```

❌ Doesn't work

```ts
merge("Hello");
merge(100);
```

**Interview Use Case:**  
Utility functions that operate only on objects.

# 5. `T extends { ... }`

Require specific properties.

```ts
function printName<T extends { name: string }>(user: T) {
    console.log(user.name);
}
```

Works:

```ts
printName({
    name: "Fareed",
    age: 24
});
```

Fails:

```ts
printName({
    age: 24
});
```

**Use when:** You need certain fields but don't care about the rest.

# 6. `T extends keyof U`

One generic depends on another.

```ts
function getValue<T, K extends keyof T>(
    obj: T,
    key: K
) {
    return obj[key];
}
```

Usage:

```ts
const user = {
    name: "Fareed",
    age: 24
};

getValue(user, "name");
```

❌ Error

```ts
getValue(user, "salary");
```

Because `"salary"` is not a key of `user`.

**One of the MOST asked TypeScript interview questions.**

# 7. `keyof`

Accept only object keys.

```ts
type User = {
    name: string;
    age: number;
};

type Keys = keyof User;
```

Result:

```ts
"name" | "age"
```

Combined with generics:

```ts
function pick<T, K extends keyof T>(
    obj: T,
    key: K
) {
    return obj[key];
}
```

# 8. `T extends keyof any`

Allows valid JavaScript property keys.

```ts
T extends keyof any
```

Equivalent to:

```ts
string | number | symbol
```

Used internally by:

```ts
Record<K, V>
```

Definition:

```ts
type Record<K extends keyof any, T> = {
    [P in K]: T;
};
```

**Interview Tip:**  
Object keys in JavaScript can only be:

- string
    
- number
    
- symbol
    

# 9. `T extends Array<any>`

Only arrays allowed.

```ts
function first<T extends any[]>(items: T) {
    return items[0];
}
```

Works:

```ts
first([1,2,3]);
first(["A","B"]);
```

Fails:

```ts
first("Hello");
```

Better written as:

```ts
function first<T>(items: T[]) {
    return items[0];
}
```

# 10. `T extends Function`

Only functions.

```ts
function execute<T extends Function>(fn: T) {
    fn();
}
```

Better practice:

```ts
function execute<T extends (...args: any[]) => any>(fn: T) {
    return fn();
}
```

**Interview Note:** Prefer function signatures over `Function`.

# 11. `T extends string`

Only strings.

```ts
function upper<T extends string>(text: T) {
    return text.toUpperCase();
}
```

Works:

```ts
upper("Hello");
```

Fails:

```ts
upper(10);
```

# 12. `T extends number`

Only numbers.

```ts
function square<T extends number>(num: T) {
    return num * num;
}
```

# 13. `T extends boolean`

Only booleans.

```ts
function toggle<T extends boolean>(flag: T) {
    return !flag;
}
```

# 14. Union Constraint

```ts
function process<T extends string | number>(value: T) {
    console.log(value);
}
```

Allowed:

```ts
process("Hello");
process(10);
```

Not allowed:

```ts
process(true);
```

# 15. Interface Constraint

```ts
interface Animal {
    name: string;
}

function speak<T extends Animal>(animal: T) {
    console.log(animal.name);
}
```

Works:

```ts
speak({
    name: "Dog",
    age: 2
});
```

Extra properties are fine because the object satisfies the required shape.

# 16. Default Generic

```ts
function create<T = string>(value: T) {
    return value;
}
```

If no type is specified or inferred, `T` defaults to `string`.

```ts
interface ApiResponse<T = unknown> {
    data: T;
}
```

`unknown` is a common default for API response types.

# 17. Multiple Constraints (Dependent Generics)

```ts
function merge<T extends object, U extends object>(
    obj1: T,
    obj2: U
) {
    return {
        ...obj1,
        ...obj2
    };
}
```

Only objects are accepted.

# 18. Conditional Generic Constraint

```ts
type Id<T extends string | number> = {
    value: T;
};
```

Usage:

```ts
const userId: Id<number> = {
    value: 101
};
```

# Most Important Interview Constraints ⭐

|Constraint|When Used|
|---|---|
|`<T>`|Generic placeholder|
|`<T, U>`|Multiple independent types|
|`T extends object`|Object utilities|
|`T extends { name: string }`|Require certain properties|
|`K extends keyof T`|Safe property access ⭐|
|`T extends keyof any`|Object key types (`string \| number \| symbol`)|
|`T extends string`|Strings only|
|`T extends number`|Numbers only|
|`T extends string \| number`|Limited union|
|`T extends SomeInterface`|Enforce a shape|
|`<T = DefaultType>`|Default generic type|
|`T extends (...args: any[]) => any`|Function constraint|

# Interview Gotchas

| Question                                            | Answer                                                                                      |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Does `extends` mean inheritance here?               | ❌ No. In generics, it means **"must satisfy"** or **"must be assignable to"**.              |
| What is the most commonly asked generic constraint? | `K extends keyof T` for type-safe property access.                                          |
| Why use `T extends object`?                         | To prevent primitives like `string`, `number`, and `boolean` from being passed.             |
| Why avoid `T extends Function`?                     | Prefer a specific function signature like `(...args: any[]) => any` for better type safety. |
| Can generics have default types?                    | ✅ Yes, using `<T = DefaultType>`.                                                           |
