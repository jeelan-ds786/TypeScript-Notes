
# Union Types

A **Union Type** allows a variable to hold **multiple possible types**.

### Syntax

```ts
let value: string | number;
```

Meaning:

```txt
value can be a string
OR
value can be a number
```

### Example

```ts
let userId: string | number;

userId = 101;
userId = "EMP101";
```

✅ Valid

```ts
userId = true;
```

❌ Error

### Quick Revision

- `|` means **OR**
    
- `string | number` → string OR number
    

# Why Do We Need Union Types?

Real-world APIs often return different types.

### Example

Employee ID

```ts
let employeeId: string | number;
```

Some systems:

```txt
101
```

Others:

```txt
"EMP101"
```

Without unions you'd have to pick only one type.

### Quick Revision

- Union types model real-world variability.
    

# Union Types with Type Inference

### Can TypeScript Infer This?

```ts
let userId = 101;
```

TypeScript infers:

```ts
let userId: number;
```

Now:

```ts
userId = "EMP101";
```

❌ Error

### Why?

Because inference decided the variable is a `number`.

### Quick Revision

- Inference chooses a specific type.
    
- It won't automatically create a union.
    

# When Must We Explicitly Define a Union?

Whenever a variable may hold different types over time.

### Example

```ts
let userId: string | number;

userId = 101;
userId = "EMP101";
```

### Another Example

```ts
let response: string | null;
```

```ts
response = "Success";
response = null;
```

### Quick Revision

- Multiple allowed types ⇒ explicit union.
    

# Union Type with Arrays

### Example

```ts
let values: (string | number)[];
```

```ts
values = [1, 2, 3];
values = ["A", "B"];
values = [1, "A", 2, "B"];
```

### Quick Revision

- `(string | number)[]`
    
- Array elements can be either type.
    

# Type Narrowing (Very Common Interview Question)

### Problem

```ts
let value: string | number;
```

Can we do?

```ts
value.toUpperCase();
```

❌ No

Because TypeScript doesn't know if it's a string or number.

### Solution

```ts
if (typeof value === "string") {
  value.toUpperCase();
}
```

Now TypeScript narrows the type to `string`.

### Example

```ts
if (typeof value === "number") {
  console.log(value.toFixed(2));
}
```

### Quick Revision

- Union Types + `typeof` = Type Narrowing
    

# Union Types in Functions

### Example

```ts
function printId(id: string | number) {
  console.log(id);
}
```

Valid calls:

```ts
printId(101);
printId("EMP101");
```

### Quick Revision

- Functions often use unions for flexible inputs.
    

# Interview Trap: Inference vs Union

### Example 1

```ts
let value = "fareedh";
```

Type inferred:

```ts
string
```

NOT

```ts
string | number
```

### Example 2

```ts
let value: string | number = "fareedh";
```

Now later:

```ts
value = 101;
```

✅ Valid

### Interview Takeaway

> TypeScript inference picks the most specific type possible. If you need multiple possible types, explicitly declare a union.

### Common Interview Gotchas

|Question|Answer|
|---|---|
|What does `|` mean?|
|Can TS infer unions automatically?|Usually no for changing variable types|
|Why use unions?|Allow multiple valid types|
|How do you safely use union values?|Type Narrowing (`typeof`, guards)|
|`let x = 10` inferred as?|`number`|
|`let x: string \| number = 10` inferred as?|Explicit Union|

### Quick Revision

- Inference → One best type.
    
- Union → Multiple allowed types.
    
- Use unions when a variable/function can legitimately accept more than one type.
    

|Topic|Quick Recall|
|---|---|
|Union Type|Multiple possible types|

|Inference|Picks one specific type|
