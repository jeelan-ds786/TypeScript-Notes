

# Access Modifiers in TypeScript

- Access modifiers control **who can access class properties and methods**
    
- Used for **encapsulation** and data protection
    
- TypeScript provides:
    
    - `public`
        
    - `private`
        
    - `protected`
        
- Quick revision: **Access modifiers = visibility control for class members**
    

# `public`

```ts
class User {
  public name = "Fareed";
}

const user = new User();
console.log(user.name);
```

- Accessible from anywhere
    
- Default modifier in TypeScript
    
- Can be accessed inside class, outside class, and child classes
    

### Interview Recall

```ts
class User {
  name = "Fareed"; // same as public name
}
```

### Quick Revision

- `public` = everyone can access
    

# `private`

```ts
class User {
  private password = "123";

  showPassword() {
    return this.password;
  }
}

const user = new User();

// Error
console.log(user.password);
```

- Accessible only inside the same class
    
- Cannot be accessed outside the class
    
- Cannot be accessed by child classes
    

### Interview Recall

```ts
class Admin extends User {
  test() {
    // this.password ❌ Error
  }
}
```

### Quick Revision

- `private` = class only
    

# `protected`

```ts
class User {
  protected age = 21;
}

class Admin extends User {
  display() {
    console.log(this.age);
  }
}
```

- Accessible inside the class
    
- Accessible inside child classes
    
- Not accessible outside the class
    

### Interview Recall

```ts
const admin = new Admin();

// admin.age ❌ Error
```

### Quick Revision

- `protected` = class + subclasses
    

# Comparison

|Modifier|Same Class|Child Class|Outside Class|
|---|---|---|---|
|public|✅|✅|✅|
|protected|✅|✅|❌|
|private|✅|❌|❌|

# Common Interview Questions

|Question|Answer|
|---|---|
|Default access modifier?|`public`|
|Can child class access private members?|No|
|Can child class access protected members?|Yes|
|Can outside code access protected members?|No|
|Does JavaScript support access modifiers?|No (TypeScript feature)|
|Which modifier gives maximum restriction?|`private`|

# Interview Example

```ts
class Employee {
  public name = "John";
  protected department = "IT";
  private salary = 50000;
}

class Developer extends Employee {
  show() {
    console.log(this.name);       // ✅
    console.log(this.department); // ✅
    // console.log(this.salary);  ❌
  }
}

const dev = new Developer();

console.log(dev.name);        // ✅
// console.log(dev.department); ❌
// console.log(dev.salary);     ❌
```

### What gets printed?

```txt
John
```

### Why?

- `name` → public → accessible
    
- `department` → protected → only child classes
    
- `salary` → private → only Employee class
    

# Interview Trap

|Trap Question|Correct Answer|
|---|---|
|Is `public` required to be written explicitly?|No, it's the default|
|Can `protected` be accessed outside the class?|No|
|Can subclasses access private members?|No|
|Are access modifiers available in plain JavaScript?|No|
|Is `protected` more restrictive than `private`?|No, `private` is most restrictive|

# Quick Recall

- `public` → Everywhere
    
- `protected` → Class + Child Classes
    
- `private` → Class Only
    
- Default = `public`
    
- Most restrictive = `private`

|private|Class only|
