xx## TypeScript Master Course Index


For this TypeScript course, don't create one row per video. That would be 300+ rows and become unmaintainable.

Instead, create an **Interview Tracking Index** where:

- **Topic** = Module
    
- **Subtopic** = Core interview concepts inside that module
    
- **Notes Link** = One dedicated note per concept
    
- **Visit** = Checkbox for revision tracking
